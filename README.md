# Student Grade Calculator

## Description

The Student Grade Calculator is a Python project that takes marks
for five subjects and calculates the total marks, percentage, and grade.

## Features

- Enter student name
- Enter marks for 5 subjects
- Validate marks between 0 and 100
- Calculate total marks
- Calculate percentage
- Calculate grade
- Display student result

## Grade System

| Percentage | Grade |
|------------|-------|
| 90 - 100   | A+    |
| 80 - 89    | A     |
| 70 - 79    | B     |
| 60 - 69    | C     |
| 50 - 59    | D     |
| Below 50   | F     |

## How to Run

Open the project folder in VS Code.

Run:

python main.py
